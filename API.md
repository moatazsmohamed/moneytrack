# Module contract

All files use vanilla ES modules. Imports relative `.js`. No frameworks. Charts/Lucide global scripts loaded before app.js. Do not edit another worker's files.

## storage.js
Exports `getState()` (deep snapshot), `update(mutator)` (clone, mutate, validate, atomically persist and dispatch `window` event `moneytrack:update`; return new snapshot; throw on failure), `validateState(data)` (throw invalid), `restore(data)` (validate then save recovery backup then update), `backup()` (JSON string), `clearDemo()`, `clearAll()` (empty tx, defaults cats, empty budgets, retain prefs), `loadDemo()` (requires caller confirm; replace data with fresh demo, retain prefs), `localDate(date=new Date())` -> YYYY-MM-DD local calendar, `monthKey(date=new Date())` -> YYYY-MM, `uid()`.

State shape: `{version:1, transactions:[], categories:[], budgets:{}, prefs:{theme:'light'|'dark',language:'en'|'ar',currency:'EGP'|'USD'|'EUR'|'SAR',name:string}}`.
Transaction: `{id:string,title:string,amount:number,type:'income'|'expense',categoryId:string,date:'YYYY-MM-DD',description:string,demo?:boolean}`. Money >0 <=1e12 with max 2 decimal places. Category: `{id:string,names:{en:string,ar:string},type:'income'|'expense',icon:string,color:'#RRGGBB'}`. Budgets indexed by YYYY-MM: `{total:number,categories:{categoryId:number}}`; numbers nonnegative; category budgets only expense categories. All IDs unique, references valid, real calendar dates, array/object types exact. Import bounded to 2 MB; IDs/text lengths bounded. Category names bilingual to maintain translations. Category type cannot change while used; UI disable type when used.

## translations.js
Exports `t(key,params={})` using current prefs; falls back to human-readable English key if missing (but all keys should be provided), `money(value)` Intl currency prefs language, `number(value,digits=0)`, `formatDate(iso,options?)`, `catName(category)`, `applyLocale()` set html lang/dir/theme, `translations` object `{en,ar}`. May import storage; storage must not import translations. Use `t` for ALL UI text including notification, buttons, aria-labels, chart labels. Authors of other modules provide paired translation keys in `js/*-strings.json` for translations author to merge; JSON includes key:{en,ar}. Core translation author provides common keys used in own UI.

## ui.js
Exports `e(value)` HTML escape, `icon(name,cls='')` -> `<i data-lucide...>`, `icons()` create icons, `toast(message,type='success')`, `openModal({title,body,onSubmit,submitLabel})` body contains fields (no form); modal adds form + cancel and submit footer. onSubmit async receives FormData, form node, must throw for invalid => show error, success => close. `closeModal()`, `confirmDialog(title,message)` Promise<bool> (same custom accessible modal; no blocking native browser confirm), `download(content,name,mime)`, `empty(message,iconName='inbox')`. Modal IDs are #modal-root and toast container #toast-root; implement if missing. Handle Escape, focus trap/restore, outside click, close label. Callers handle errors with toast. On cancel no mutation.

## transactions.js
Exports `renderTransactions(container)` and `openTransaction(id=null,type='expense')`; owns module filter state search,type,category,start,end,sort,page. Search title AND description, income/expense/all, category, inclusive date range, newest/oldest/highest/lowest, page size 10. `transactionTable(list,{compact=false}={})` HTML reusable by dashboard, actions data-edit-tx and data-delete-tx. `bindTransactionActions(container)` attach actions in passed node only. `exportCSV(list=getState().transactions)` BOM UTF-8 RFC4180 safe values incl spreadsheet injection. Also exports `filterTransactions(transactions,filters)` pure utility. All entries escaped, safe category lookup; empty states. Add/edit validate; delete confirmation. Preserve draft when language/theme changes if possible.

## categories.js and budgets.js
Export `renderCategories(container)` and `renderBudgets(container)`. Categories CRUD icon/color bilingual names. Deleting a used category opens reassignment dialog requiring a same-type replacement; atomically reassign then delete category + category budget keys. Unused delete confirm. Budgets selected YYYY-MM, total and category-specific budgets, expense sum for selected month, remaining, warning >=80%, over >=100%; reset selected-month budgets only with confirm. Export `budgetSummary(month=monthKey())` -> `{total,spent,remaining,percent,categories:[{category,budget,spent,remaining,percent}]}`. Module remembers selected month across render.

## Parent modules
`dashboard.js`: renderDashboard(container), all numbers from transactions, current monthly income/expenses/savings + all-time balance, previous-month comparisons; current month selector; four charts.
`charts.js` parent implements chart lifecycle and shared monthly grouping.
`reports.js`: renderReports(container), this week/month/last month/year/custom, actual data, CSV export.
`settings.js`: renderSettings(container), prefs appearance/language/currency/name, backups import strict validate+confirm, clear/demo actions; clearly local only/no sync.
`app.js`: hash routes #dashboard #transactions #budgets #reports #categories #settings, nav + header, global search routes transactions with exported search setter optional; subscribe update => render active view, refresh shell/locale/icons. notifications derived from actual budget warnings (no fake unread counts). Avoid duplicate event bindings.
