# MoneyTrack

تطبيق إدارة أموال شخصية كامل بتقنيات HTML5 وCSS3 وVanilla JavaScript ES6، مع Chart.js وLucide. يدعم العربية والإنجليزية، RTL/LTR، الوضع الفاتح والداكن، وEGP افتراضياً. لا يوجد React أو خادم بيانات أو حساب بنكي مرتبط.

## التشغيل المحلي

فك ضغط المشروع. افتح Terminal داخل مجلد `MoneyTrack`، ثم شغّل:

```bash
python3 -m http.server 3000
```

على Windows يمكن استخدام `py -m http.server 3000`. افتح `http://localhost:3000`. يلزم خادم HTTP لأن JavaScript يستخدم modules؛ فتح `index.html` مباشرة عبر `file://` ليس طريقة تشغيل مدعومة. بديل: Live Server في VS Code.

لا يلزم تثبيت حزم JavaScript لتشغيل التطبيق. مكتبتا Chart.js وLucide مرفقتان في `js/vendor/`. يُحمّل خط Google اختياري؛ عند تعذر الشبكة يستخدم المتصفح خط النظام الذي يدعم العربية.

## البيانات والخصوصية

البيانات محفوظة في LocalStorage على نفس المتصفح ونفس أصل الموقع. لا تُزامَن تلقائياً بين الأجهزة أو بين نطاق localhost والنطاق المنشور. يبدأ الاستخدام الأول ببيانات تجريبية موسومة ويمكن حذف التجريبي فقط من الإعدادات دون حذف معاملاتك الخاصة. تغيير عملة العرض لا يحوّل قيم الأموال.

صدّر JSON من الإعدادات بصورة منتظمة. استيراد نسخة سليمة يتطلب تأكيد استبدال البيانات الحالية؛ تُحفظ نسخة استرجاع محلية قبل الاستبدال. حجم النسخة الأقصى 2 MiB بصيغة UTF-8. CSV يُصدر بيانات الفلاتر المختارة ويحمي حقول النصوص من الصيغ التنفيذية في الجداول. لا ترسل نسختك الاحتياطية الخاصة إلى مستودع عام.

إذا تعذر التخزين أو كانت البيانات المحفوظة تالفة، يعرض التطبيق تحذيراً ويمنع التغييرات العادية حفاظاً عليها. يمكنك استخدام استعادة أو مسح مؤكد من الإعدادات. مسح بيانات التطبيق لا يمس بيانات المواقع الأخرى، ويحتفظ بالتفضيلات.

## النشر المجاني

### GitHub وVercel

أنشئ مستودع GitHub خاصاً أو عاماً حسب رغبتك، ثم ارفع الملفات دون `.env` أو أي token أو ملفات نسخ بيانات شخصية. اتصل بـ GitHub من Vercel واختر Import Project. المشروع لا يحتاج قاعدة بيانات أو متغيرات سرية.

الإعدادات: Framework Preset: Other؛ Build Command: `python3 build.py`؛ Output Directory: `dist`. هذه القيم موجودة أيضاً في `vercel.json`. اضغط Deploy. إذا لم يتوفر Python في بيئة البناء، يمكنك استضافة المجلد الجذري مباشرة كتطبيق Static بدون build command؛ `index.html` و`css/` و`js/` و`assets/` هي ملفات التشغيل كاملة.

### GitHub Pages

ارفع المشروع إلى المستودع، ثم افتح Settings → Pages → Deploy from a branch، واختر `main` و`/(root)`. المسارات داخل التطبيق مبنية على hash وروابط الأصول نسبية، لذلك يعمل أيضاً تحت مسار مستودع. لا توجد حاجة لإعادة توجيه SPA.

### أي استضافة Static أخرى

شغّل `python3 build.py` ثم ارفع محتويات `dist/` إلى استضافة Static مثل Netlify أو Cloudflare Pages. أو ارفع ملفات التشغيل الجذرية مباشرة. HTTPS مستحسن، ولا يحتاج التطبيق مفاتيح GitHub/Vercel داخل المصدر.

## الاختبارات

يتطلب اختبار الحسابات Node.js 22 أو أحدث:

```bash
node --test tests/core.test.js
```

اختبار المتصفح الحقيقي متاح بعد تشغيل الخادم عبر Console:

```javascript
await (await import('/tests/browser-smoke.js?run=1')).runSmoke()
```

الاختبار يستبدل بيانات متصفح الاختبار مؤقتاً ببيانات اصطناعية ثم يعيد حالته السابقة في `finally`. نفّذه في ملف متصفح منفصل لا يستخدم بياناتك المالية الحقيقية. يُعيد تقريراً بالنتائج في `window.moneyTrackTestResults`. راجع `TESTED_FEATURES.md` لتفاصيل ما اختُبر فعلياً.
